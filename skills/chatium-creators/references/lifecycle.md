# Карточка, заявка и обновления

Перед редактированием прочитай выбранную карточку и профиль, затем обновляй только нужные
поля. Категории функциональности и скиллов имеют независимые справочники. Состояние
подключения и права проверяются сервером, включая каждый ID решения.

Для ссылки на редактор используй origin и preview query из `context.links.cabinet`:
плагин `/cabinet~plugins/<profile.id>/edit/<solution.id>`,
шаблон `/cabinet~templates/<profile.id>/edit/<solution.id>`.
Создавай URL через URL API, сохрани `__chtmPreviewMode__`, не подставляй ID в другой аккаунт.

## Готовность и отправка

`getCreatorSolution().publicationIssues` содержит машинные причины:

| Причина | Что сделать |
| --- | --- |
| profile | Заполнить валидное имя/slug/email и описание креатора |
| agreement | Владелец должен лично принять оферту по links.agreement |
| creator-account | Привязать рабочий аккаунт к профилю с подтверждением владельца |
| creator-paid-seat | Проверить купленное действующее место владельца профиля в одном из привязанных аккаунтов; не место коллеги и не trial |
| creator-billing-unavailable | Сохранить черновик, сообщить о сбое проверки; повторить после восстановления |
| description | Название, короткое и полное описание решения |
| languages | Указать поддерживаемые языки |
| categories | Выбрать функциональные категории, если hasFunctionality=true |
| archive | Загрузить защищённый ZIP шаблона |
| skills | Для каждого заявленного скилла добавить название, описание и категории |

Когда пользователь поручил отправить готовое решение, вызови `requestCreatorPublication`
со свежим updatedAt. При success=false покажи issues и исправь доступные поля; юридический
акцепт передай владельцу. При success=true перечитай состояние:

- isPublished=false, reviewRequestedAt=null — черновик;
- isPublished=false, reviewRequestedAt заполнено — заявка отправлена;
- isPublished=true — карточка опубликована; отправка повторно ничего не публикует.

Не говори «опубликовано», когда лишь создано приложение, сохранён черновик или отправлена
заявка. Автоматического обещания срока модерации, уведомлений об итогах или публичного
slug нет. Полный процесс принятия/отклонения ещё не реализован.

## Изменения после отправки/публикации

Сохранение карточки или нового ZIP снимает прежнюю заявку: снова проверь и отправь её,
если это входит в поручение. `withdrawCreatorPublication` явно отзывает текущую заявку.
`unpublishCreatorSolution` снимает карточку с витрины, сохраняя покупки и установленные
приложения. Это не удаление продукта и не отзыв ранее выданных ZIP-ссылок.

У опубликованной карточки изменение метаданных действует сразу, как и замена актуального
архива для уже имеющих доступ. Отдельной черновой редакции/версии на проверке нет.
Перед таким изменением объясни конкретный эффект, если поручение не определяет его явно;
при запросе «подготовь новую версию» можно подготовить локальный пакет и описание до
команды заменить действующее решение. Не снимай его с публикации сам для обхода этого ограничения.

## Ошибки

| Код/ситуация | Действие |
| --- | --- |
| STORE_CREATOR_ACCOUNT_CALLER_REQUIRED | Исполнять в account/Workspace, не из плагина/agent-process |
| Ошибка real user/Developer | Войти нужным пользователем с реальной ролью; не повышать её самостоятельно |
| STORE_CREATOR_CONNECTION_REQUIRED | Повторно получить context, проверить отзыв/смену владельца, начать подтверждение |
| STORE_CREATOR_REQUEST_EXPIRED | Новый begin; старый токен одноразовый |
| STORE_CREATOR_ALREADY_CONNECTED | Не переключать кабинет молча; согласованный disconnect и новое подтверждение |
| STORE_CREATOR_ACCOUNT_ALREADY_BOUND | Аккаунт привязан к другому профилю; владелец должен сначала отвязать его в интерфейсе, одного disconnect недостаточно |
| STORE_CREATOR_OWNER_REQUIRED | Подтверждает именно владелец центрального кабинета |
| STORE_CREATOR_SOLUTION_NOT_FOUND | ID отсутствует или относится к другому кабинету; прочитать свои списки |
| STORE_CREATOR_CONFLICT | Перечитать, сравнить, сохранить чужие изменения |
| STORE_CREATOR_SLUG_TAKEN | Проверить собственные записи после возможного частичного успеха |
| STORE_CREATOR_DIRECTORY_NOT_PUBLISHED | Проверить published source и discovery; не регистрировать другую папку наугад |
| STORE_CREATOR_DIRECTORY_ALREADY_REGISTERED | Сопоставить существующую пару directory/slug |
| STORE_CREATOR_PLUGIN_ALREADY_BOUND | Не переносить чужой плагин; нужен его владелец/поддержка |
| STORE_CREATOR_PLUGIN_SOURCE_REQUIRED | Устанавливать приватный плагин в его исходном аккаунте |
| STORE_CREATOR_PROTECTED_ZIP_REQUIRED | Загрузить ZIP по creator upload URL, не публичный и не чужой файл |
| STORE_CREATOR_USE_ACCOUNT_SDK | Устаревший путь binding закрыт; перейти к нынешнему подтверждению |
| Неизвестные поля/категории/языки | Проверить typings и актуальные справочники, исправить запрос |

Если подпись/копирование архива или runtime отказывает без указанного кода, сохрани
безопасное сообщение ошибки и проверь выбранный account context. Не делай ZIP публичным
и не передавай токены в отчёт для «исправления» доступа.
